# web-programming-final

Final project for Web Programming course (Spring 2026)

웹프로그래밍 수업에서 진행한 기말 프로젝트를 정리한 저장소입니다.

## 1. 프로젝트 소개

HTML, CSS, JavaScript를 활용하여 제작한 자기소개 홈페이지입니다.

## 2. 사용 기술

- HTML5
- CSS3
- JavaScript

## 3. 페이지 구성

- intro.html
  - 이름 입력 및 현재 날짜와 시간 출력

- profile.html
  - 자기소개 및 기본 정보

- timetable.html
  - 학기 시간표 소개

- food.html
  - 좋아하는 음식 소개

- mbti.html
  - MBTI 유형 입력을 통한 궁합 확인

## 4. 주요 기능

- 사용자 이름 입력
- 현재 날짜 및 시간 출력
- 자기소개 페이지
- 학기 시간표 제공
- 좋아하는 음식 소개
- MBTI 유형별 궁합 확인

## 5. 참고사항

- HTML, CSS, JavaScript의 기본 문법을 활용하여 제작한 웹페이지입니다.
- 페이지 간 이동과 사용자 입력, 조건문 등을 활용하여 기본적인 웹 프로그래밍 기능을 구현하였습니다.
- 디자인은 과도한 효과보다 가독성과 사용성을 고려하여 구성하였습니다.
